# 推理示例 (Python)


该目录包含使用 jetson-inference 进行图像识别、目标检测、语义分割和其他计算机视觉 DNN 的 Python 示例。  有关运行这些示例的信息，请参阅[教程步骤](../../README-CN.md#hello-ai-world-inference-only)。


有关使用 numpy 数组的示例，请参阅 [`cuda-from-numpy.py`](https://github.com/dusty-nv/jetson-utils/blob/master/python/examples/cuda-from-numpy.py) 和 [`cuda-to-numpy.py`](https://github.com/dusty-nv/jetson-utils/blob/master/python/examples/cuda-to-numpy.py)


> **注意**: 对于 C++ 示例，请参阅 [**`jetson-inference/examples/`**](../../examples)。
