# 数字工作流程


深度神经网络 (DNN) 和机器学习新手？  学习有关训练和推理的[入门入门](deep-learning-CN.md)。


<a href="https://github.com/dusty-nv/jetson-inference/blob/master/docs/deep-learning.md"><img src="https://github.com/dusty-nv/jetson-inference/raw/master/docs/images/digits-samples.jpg" width="800"></a>


使用 NVIDIA 深度学习工具，可以轻松**[开始](https://github.com/NVIDIA/DIGITS/blob/master/docs/GettingStarted.md)** 训练 DNN 并将其高性能地部署到现场。  独立 GPU 通常用于服务器、PC 或笔记本电脑中进行 DIGITS 训练，而 Jetson 和集成 GPU 用于嵌入式外形。


<a href="https://github.com/dusty-nv/jetson-inference/blob/master/docs/deep-learning.md"><img src="https://github.com/dusty-nv/jetson-inference/raw/master/docs/images/digits-workflow.jpg" width="700"></a>


NVIDIA [DIGITS](https://github.com/NVIDIA/DIGITS) 用于在云或 PC 中的带注释数据集上交互式训练网络模型，而 TensorRT 和 Jetson 用于在现场部署运行时推理。 TensorRT 使用图形优化和半精度 FP16 支持双倍以上的 DNN 推理。  DIGITS 和 TensorRT 共同形成了一个有效的工作流程，用于开发和部署能够实现高级人工智能和感知的深度神经网络。
